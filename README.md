# Bachelor Thesis

Monte Carlo Portfolio Risk Analysis | 40/60 Equity-Bond Portfolio
Simulation framework for portfolio risk assessment built in R. Downloads historical price data from Yahoo Finance (S&P 500 & U.S. Treasury ETF), models daily returns via Geometric Brownian Motion across 100,000 simulated paths over a 1-year horizon, and computes core risk metrics: Value at Risk (VaR 95%), Expected Shortfall (ES), and Expected Return. 

Results are visualised through an annotated return distribution plot.
Stack: R · quantmod · PerformanceAnalytics · ggplot2
